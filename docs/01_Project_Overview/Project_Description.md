FoodFinda is a Java application that simulates a small food delivery operation. The project is intended to provide a user interface for placing orders and viewing delivery activity. While that UI is being integrated, the current console prototype can place an order using a customer name, restaurant, food item, delivery coordinate, and urgency flag. The simulator selects the nearest available rider, generates a route on a simple grid, and advances an order through pickup and delivery.

The application is educational: it demonstrates basic object-oriented modeling, collection sorting, nearest-rider selection, and grid path construction. It stores data only in memory, so orders reset when the program exits.

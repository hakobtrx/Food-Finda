# Project Description

FoodFinda is a Java console program that simulates a small food delivery operation. A user can place an order with a customer name, restaurant, food item, delivery coordinate, and urgency flag. The simulator selects the nearest available rider, prints a route on a simple grid, and lets the user advance the order through pickup and delivery.

The application is educational: it demonstrates basic object-oriented modeling, collection sorting, nearest-rider selection, and grid path construction. It stores data only in memory, so orders reset when the program exits.

# Objectives and Scope

## Objectives

- Accept simulated food orders.
- Mark orders urgent and list urgent orders first.
- Assign the closest available rider to a restaurant.
- Build a deterministic path across a two-dimensional city grid.
- Track order progress from placed to assigned, picked up, and delivered.
- Update rider location and availability when delivery completes.

## Included

- Console user interface.
- In-memory sample restaurants and riders.
- Manhattan-distance rider selection and grid route generation.
- Manual status advancement to simulate delivery.

## Out of scope

- Real maps, road networks, or GPS.
- Payment processing or restaurant integrations.
- Persistent storage or user accounts.
- Live rider location updates or concurrent dispatch.

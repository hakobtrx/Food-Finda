# UI Design

FoodFinda is intended to provide a user interface for operating the delivery simulator. UI integration is in progress. The current text-based menu in `FoodFindaApp` is a temporary prototype for exercising the workflow; it offers place order, view orders, advance delivery, and view riders. Its input validation provides a behavioral reference for the UI.

The interface should support order creation and show urgency, item, restaurant, status, rider, destination, and planned grid route. The `screenshots` directory is reserved for captures as UI screens are implemented.

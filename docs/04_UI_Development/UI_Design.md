# UI Design

The current interface is a text-based menu in `FoodFindaApp`. It offers four actions: place an order, view orders, advance a delivery, and view riders. Input is read from the console and validated for required text, integer coordinates, menu selections, and yes/no urgency.

When an order is placed, the app displays the selected rider and planned grid route. The order list shows urgency, item, restaurant, status, rider, and destination. No graphical UI is currently implemented. The `screenshots` directory is reserved for future UI captures.
